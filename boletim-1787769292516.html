Boletim de Segurança Agility Networks - Vulnerabilidades Críticas no Next.js (CVE-2026-75604)
==========================================================
Falha no Next.js possibilita execução remota de código em aplicações hospedadas no Windows
==========================================================
Descrição da Vulnerabilidade

Duas falhas críticas no Next.js foram identificadas, permitindo a execução remota de código não autenticada em aplicações hospedadas no Windows que utilizam a API de Otimização de Imagem para processar imagens AVIF.

Essas vulnerabilidades podem expor dados sensíveis, alterar conteúdo do lado do servidor ou interromper a disponibilidade da aplicação.

A CVE-2026-75604 afeta aplicações que utilizam os roteadores "Pages" ou "App" sem componentes de cache, ocorrendo quando a aplicação roda em um servidor com sistema de arquivos Windows. A causa está relacionada a um problema técnico de travessia de caminho (CWE-22).

==========================================================
Produtos e Versões Afetadas

Segundo a publicação analisada, os impactos ocorreram em:

Next.js: Builds de 13.4 até versões antes de 15.5.24 e de 16.0 até antes de 16.3.3.

Fontes adicionais confirmam que o problema impacta:

Afeta clientes que utilizam instalações Next.js conectando via API de Otimização de Imagem.
==========================================================
Impacto Potencial

A falha gera:

Exposição de dados sensíveis;

Alteração de conteúdo do lado do servidor;

Interrupção da aplicação;

Afeta especialmente ambientes de produção, causando riscos severos de segurança.
==========================================================
Principais Características da Ameaça

O problema é causado por entrada controlada pelo atacante, quebrando restrições de elemento de caminho;

O erro é reproduzido de forma consistente após falha em restringir elementos especiais;

A falha não impacta sistemas sem APIs de Otimização de Imagem ativadas, o problema ocorre em sistemas Windows;

A falha afeta principalmente organizações que hospedam aplicações Next.js em ambientes Windows.

Observações Complementares:

Vercel corrigiu a falha em Next.js 15.5.24 e 16.3.3;

Não há solução alternativa para sistemas Windows afetados.
==========================================================
Recomendações de Mitigação

Correção Oficial (Vercel):

A Vercel lançou uma atualização emergencial que corrige as vulnerabilidades e restaura a segurança da aplicação:

Next.js: Versão 15.5.24 ou superior;

Next.js: Versão 16.3.3 ou superior.

Ações Recomendadas:

Atualizar para as versões corrigidas imediatamente;

Revisar caminhos de upload de imagens públicas;

Verificar logs para solicitações incomuns;

Recompilar contêineres de produção;

Atualizar dependências e arquivos de lock;

Utilizar monitoramento contínuo para detectar anomalias.

Em casos onde a atualização não pode ser aplicada imediatamente:

Desativar temporariamente a otimização AVIF;

Monitorar padrões de travessia de caminho.
